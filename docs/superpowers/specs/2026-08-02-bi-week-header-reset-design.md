# BI 新周日期与数据清空修复设计

## 问题

自动创建新周工作表时，程序复制上一周期工作表。左侧成熟单品日期表头会更新，但 BI 上新区域的直播价格日期表头不会更新，因此新页 `N3:R3` 仍显示上一周日期。

## 目标行为

- 新页左右两组日期表头都改成目标周星期一至星期五。
- BI 数据区从第 4 行开始全部清空，包括上架日期、型号、形态、价格、直播价格和新卖点。
- 保留 BI 标题、二级表头、第三行日期单元格的格式，以及整张工作表的列宽、合并单元格和左侧产品模板。
- 已经存在的当周工作表不自动清空，避免删除已采集的有效数据；修复只作用于自动复制创建的新页。

## 实现

`ExcelService.prepare_copied_sheet()` 在识别 `上新监控` 起始列后，继续从 BI 区域第 3 行识别与直播价格相邻的 5 个日期表头，将其写成目标周日期。现有从 `data_start_row` 到 `max_row`、从 `right_start_column` 到 `max_column` 的清空逻辑保留并增加回归测试。

如果模板没有识别出 5 个 BI 日期表头，但存在 BI 区域，则抛出清晰的 `WorkbookLayoutError`，避免悄悄生成日期错误的新页。

## 验证

- 测试复制 7.20-7.24 模板生成 7.27-7.31，断言 C3:G3 与 N3:R3 均为新日期。
- 在 J4:S5 填入旧 BI 内容，断言新页全部清空，表头与样式保留。
- 完整 Python 回归通过。
- 用真实模板副本模拟生成下一周工作表，渲染顶部区域进行视觉检查。
