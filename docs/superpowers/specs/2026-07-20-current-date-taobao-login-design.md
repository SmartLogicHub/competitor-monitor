# 手动运行当前日期与淘宝登录浏览器设计

## 背景

Web 控制台目前把配置中保存的 `run_date` 回填到日期输入框，手动运行时又把该值提交给后端。因此，旧日期会跨天残留。2026-07-20 点击手动运行时实际提交了 2026-07-19，触发“非周一至周五监控日期”校验并在商品识别前结束。

自动采集遇到的淘宝页面不是模板故障。淘宝页面明确提示商家账号（含子账号）不支持访问其他店铺商品详情，需要在采集专用浏览器中登录买家账号。

## 目标

1. Web 控制台的手动采集固定使用运行电脑的当前本地日期，不再使用持久化的旧日期。
2. 保留现有的周工作表自动创建逻辑：当前日期对应的工作表不存在时，仍调用现有 Excel 服务复制并创建本周工作表。
3. 在“淘宝账号”区域增加“打开淘宝登录网页”按钮，让用户在采集程序共用的浏览器配置中登录买家账号并保存 Cookie。
4. 登录浏览器与采集任务互斥，防止同时占用同一浏览器配置目录。
5. 源码运行和 PyInstaller EXE 部署均可用。

## 非目标

- 不绕过淘宝的商家账号访问限制。
- 不修改商品采集、SKU 匹配、价格写入、活动识别或企业微信通知逻辑。
- 不修改定时任务的日期语义；定时任务继续默认使用系统当天日期，并保留命令行 `--date` 的测试/补采能力。
- 不删除已有模板或登录状态。

## 设计

### 手动运行日期

前端手动运行请求不再从 `cfg-run-date` 读取或提交 `run_date`。后端现有 `WebApiService.run_task` 在请求未提供日期时使用本机 `date.today()`，因此它成为 Web 手动运行的唯一日期来源。日期展示字段改为只读的“当前日期”，每次加载配置和点击运行前均刷新为本地日期，避免误导。

配置保存不再写入 Web 页面展示的运行日期。后端仍接受显式 `run_date`，供定时任务命令行 `--date`、测试和受控补采使用。

现有日采集流程继续调用 `get_or_create_current_sheet`。测试必须证明：以当前日期运行且对应周工作表不存在时，仍会自动创建工作表。

### 淘宝登录浏览器

新增一个小型登录浏览器入口，复用采集配置中的：

- `browser_user_data_dir`
- Chrome 可执行文件探测规则
- Playwright 持久化上下文启动参数

它打开淘宝首页并保持窗口，直到用户关闭浏览器。关闭后，持久化浏览器目录中的 Cookie/本地存储由后续自动采集复用。登录入口不读取或回显账号密码，也不记录 Cookie。

Web 后端新增登录会话状态和接口：

- `POST /api/session/open`，参数 `{ "target": "taobao" }`
- `GET /api/session/status`，返回是否正在打开登录浏览器

后端异步启动独立登录进程，接口立即返回，不阻塞 Web 服务。源码模式启动 Python 登录入口；冻结后的 EXE 模式使用同一打包程序支持的内部启动参数，确保部署包无需额外 Python 环境。

### 互斥与错误处理

- 采集任务正在运行时，拒绝打开登录浏览器，并返回明确中文提示。
- 登录浏览器正在运行时，拒绝再次打开，也拒绝启动采集任务。
- 登录进程退出后，状态自动恢复为“已关闭”。
- Chrome 启动失败时记录错误并在页面提示，不改变或清除现有浏览器状态。
- “清除淘宝浏览器状态”保持现有行为，但登录浏览器打开时禁止执行。

### 前端交互

按钮放在现有“清除淘宝浏览器状态”按钮附近，主操作文案为“打开淘宝登录网页”。旁边显示“登录浏览器已打开”或“登录浏览器已关闭”。打开期间按钮禁用；采集运行期间按钮也禁用。提示文字说明：请登录买家账号，登录完成后直接关闭窗口，状态会自动保存供采集使用。

## 测试

1. 前端测试证明手动运行请求不包含旧 `run_date`，日期展示为当前本地日期且只读。
2. Web API 测试证明未提供日期时使用注入的 `today_provider`，不读取配置中的旧日期。
3. Excel 回归测试证明目标周工作表缺失时仍自动创建。
4. 会话接口测试覆盖：正常启动、重复点击、采集运行中拒绝、登录打开时拒绝采集、进程退出后恢复、启动失败。
5. 静态页面测试验证按钮、状态和提示文案存在。
6. 运行完整 Python 与前端测试，并检查 PyInstaller spec 包含新增登录入口所需模块。

## 验收标准

- 即使配置里保存了昨天或周日，点击“手动运行”也显示并使用电脑当天日期。
- 当前周工作表缺失时仍按原规则自动创建，再识别和采集商品。
- 点击“打开淘宝登录网页”会打开采集专用浏览器的淘宝页面；登录买家账号、关闭窗口后，再次自动采集能复用该登录状态。
- 同一浏览器配置不会被登录与采集同时占用，冲突时用户看到清晰提示。
