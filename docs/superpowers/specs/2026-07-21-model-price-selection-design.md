# 型号与套餐价格选择设计

## 目标

根据 Excel 型号名称选择正确的商品基础款、Pro、Ultra 或可识别礼盒套餐，避免把同页“起价”写入不对应的型号。

## 已确认业务规则

- 型号未写 `Pro`、`Ultra` 等升级标记时，按官方标配的基础款处理。
- 型号写了 `Pro` 或 `Ultra` 时，只要页面 SKU 标记匹配该升级型号即可，不要求 SKU 文本重复基础型号名。
- 型号带礼盒/套餐描述时，页面必须存在相应礼盒套餐；否则该具体子型号写入 `/`，不得回退到普通 Ultra。
- 商品链接或价格变化后，每次基于当前页面的 SKU/套餐重新匹配；没有匹配到的具体型号写入 `/`，不使用历史价格。
- 未完成相应型号或套餐确认时，页面“¥xxx 起”不能充当该行价格。

## 数据流

1. 先从初始 SKU 数据中读取套餐与型号维度。
2. 选择礼盒匹配套餐，否则选择官方标配套餐。
3. 对于 Pro/Ultra，只筛选含相应升级标记的 SKU；对基础款，筛选不含 Pro/Ultra 的 SKU；礼盒/套餐子型号还必须匹配其具体套餐标记。
4. 仅从筛选后的 SKU 价格取值；总起价只作为页面状态观察，不能覆盖确认的 SKU 价。
5. 无候选值时，由运行层报告失败/待复核；确认下架则写 `/`。

## 回归范围

- 基础型号 `S7S` 在 `AI2` 与 `Ultra` 共存时只取基础款价格。
- `S7S Ultra` 在 SKU 仅写 `Ultra` 时仍能匹配 Ultra 价格。
- `S7S Ultra 520 告白礼盒` 在存在礼盒套餐时取礼盒 Ultra 价格；不存在礼盒套餐时回退官方标配 Ultra。
- `S7S Ultra 520告白礼盒` 缺少 `520` 与礼盒套餐标记时写入 `/`，不从历史列填充。
